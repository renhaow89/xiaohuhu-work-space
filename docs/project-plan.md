# Xiaohuhu Work Space 项目规划

## 当前核心目标

建立一个真正属于个人、脱离第三方工作台平台、手机和电脑都可以使用的个人工作空间。

第一阶段不追求 AI、远程电脑文件访问等复杂能力，优先把工作台本身做稳定、可用、可同步。

## 第一阶段：独立个人工作台

- 脱离第三方平台依赖
- 完成独立网页端
- 保留并迁移原有核心功能
- 统一数据模型
- 统一存储层
- 任务管理
- 阅读管理
- 科研记录
- 复盘与日常记录
- 本地数据稳定保存
- 数据导入、导出与备份
- 移动端与桌面端网页适配

## 第二阶段：多设备同步

- 云端数据库
- 用户认证
- 手机与电脑数据同步
- 冲突处理
- 自动备份
- 恢复历史数据

## 第三阶段：体验与扩展

- PWA / 安装到手机主屏幕
- 更完善的 Dashboard
- 搜索与标签
- 快速记录
- 数据统计
- 模块化扩展机制

## 暂缓功能

以下功能暂时不进入当前开发主线，但架构继续保留扩展位置：

- AI Agent
- AI API 接入
- MCP 工具
- Windows 本地文件远程访问
- Local Agent
- 电脑文件远程访问与同步

等核心工作台和多设备同步稳定后，再根据实际使用需求决定是否启用这些能力。

## 开发原则

- 先解决真正长期使用的问题
- 不为暂时没有需求的功能增加复杂度
- 数据优先，界面其次，扩展能力最后
- 保留旧数据和回滚能力
- 每个阶段都应当保持可运行
